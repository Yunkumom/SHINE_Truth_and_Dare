# One Image, Many Gifts — Approved Design

The owner requires every game image to begin with a keepsake purpose and every completed game to offer a gift output. The first implementation applies this reusable rule to Australia Find It.

## Experience

- After an answer is revealed or a find is confirmed, show `製作紀念明信片 · MAKE POSTCARD` beside Next Card.
- Open a two-sided electronic-postcard maker without leaving the current in-memory round.
- Front preserves the complete puzzle artwork and adds the bilingual card title plus the owner’s Yunkumom signature during composition.
- Back provides classic postcard structure, an optional recipient, optional sender, and an editable gift message.
- Preview either side and share/download both 1800 × 1200 PNG files together.

## Reuse and privacy

- The exporter is generic and accepts any image, title, subtitle, and stable ID so later games can call the same path.
- The governed artwork master remains unchanged; branding belongs to output composition.
- The exact owner-supplied source and transparent derivative live in Library with prompt and provenance.
- Recipient, sender, and message never leave React memory and are never persisted or transmitted by the product.
