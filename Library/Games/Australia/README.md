# Australia Find It Library / 澳洲大家來找碴素材庫

This Library owns the reusable source material for the 50-card bilingual `大家來找碴 · AUSTRALIA FIND IT` game.

本 Library 管理中英雙語五十張 `大家來找碴 · AUSTRALIA FIND IT` 遊戲的可重複使用原始素材。

- Card book and answer keys / 卡書與答案：`AUSTRALIA_FIND_IT_CARD_BOOK.md`
- Final prompt set / 最終提示詞：`PROMPTS.md`
- Hidden-map Library masters / 藏地圖主圖：`Library/Images/Species/Australia/field-journal-embedded-map-v2/`
- Difference Library masters / 找不同主圖：`Library/Images/Games/Australia/find-it-v1/difference/`
- Integrity manifest / 完整性清單：`Library/Images/Games/Australia/find-it-v1/MANIFEST.sha256`
- Runtime derivatives / Runtime 副本：`Versions/v47/app/encounter/assets/australia-find-it-v1/`
- Reusable gift-output standard / 可重用紀念輸出規範：`Library/Card-Designs/YUNKUMOM_KEEPSAKE_OUTPUT_STANDARD.md`
- Governed brand assets / 受治理商標資產：`Library/Brand/Yunkumom/`

Library masters are text-free 1024 × 1536 RGB PNG files; runtime derivatives are optimized WebP copies and never replace or govern the masters.

Library 主圖皆為無文字 1024 × 1536 RGB PNG；runtime derivatives 僅為最佳化 WebP 副本，絕不取代或治理主圖。

After any round is revealed, the same master can be composed as a branded two-sided electronic postcard. Branding is applied only during output so the source image remains reusable.

每局揭曉後，同一張 master 都可組合成帶有 Yunkumom 商標的雙面電子明信片；商標只在輸出時加入，因此原始圖片能持續多用途重用。
