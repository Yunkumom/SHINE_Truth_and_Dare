# Australian Native Species Keepsake Card Book / 澳洲原生物種紀念卡書

Date: 2026-08-26
Scope: 25 Library-only keepsake cards; 15 vertebrates, 5 plants, and 5 invertebrates

## 01 紅大袋鼠 / Red Kangaroo

- Scientific name / 學名: *Osphranter rufus*
- Group / 類別: vertebrate / 脊椎動物
- Front line / 正面短語: `把遼闊，跳成自己的方向。` / `Turn wide horizons into your own direction.`
- Back story / 卡背故事: 紅大袋鼠適應澳洲乾燥內陸，強健後肢與長尾幫助牠高效跳躍並保持平衡。 / Red kangaroos are adapted to Australia's dry interior, using powerful hind limbs and a long tail for efficient hopping and balance.
- Blessing / 紀念祝福: `願你每次前進，都比想像更遠。` / `May every leap carry you farther than imagined.`
- Source / 來源: [Australian Museum, mammals](https://australian.museum/learn/animals/mammals/)
