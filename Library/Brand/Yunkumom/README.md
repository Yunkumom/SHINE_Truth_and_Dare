# Yunkumom Brand Assets

This folder owns the reusable Yunkumom mark used on keepsakes, gift files, and electronic postcards.

- `yunkumom-owner-source-v1.png` is the untouched owner-supplied source received on 2026-08-26.
- `yunkumom-logo-transparent-v1.png` is the project-ready transparent derivative created with the built-in image-generation tool in background-extraction mode.
- The transparent derivative preserves the complete symbol, the exact `Yunkumom` word, their proportions, and their relative placement; only the white/off-white background was requested for removal.
- Runtime copies must remain byte-identical to this Library derivative and cite this folder.
- Do not redraw, reinterpret, recolor, stretch, crop, or place competing marks beside it.

The final extraction prompt is recorded in `TRANSPARENT_BACKGROUND_PROMPT.md`.

## 用途

此資料夾管理可重複使用於紀念卡、禮物檔案與電子明信片的 Yunkumom 商標。

- `yunkumom-owner-source-v1.png` 是 2026-08-26 收到、未改動的擁有者原始檔。
- `yunkumom-logo-transparent-v1.png` 是以內建圖片生成工具、`background-extraction` 模式製作的透明衍生檔。
- 所有 runtime 副本必須與此透明 Library 檔案逐位元相同，並保留來源追溯。
- 不得重畫、重新詮釋、改色、拉伸、裁切或在旁邊放置競爭性標誌。
