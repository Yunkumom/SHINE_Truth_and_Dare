# Main App V37 Source / 主應用程式 V37 原始碼

This is the React, TypeScript, and Vite source for Encounter Cards V37. It preserves the complete v36 experience and adds a fixed three-column desktop studio, compact tabbed layout editor, enlarged centre authoring preview, inert right phone preview, and fully interactive Test mode.

此處保存 Encounter Cards V37 source；完整保留 v36 體驗，並新增固定三欄桌面工作室、精簡分類版面編輯器、中央大型編輯預覽、右側不可互動手機預覽，以及完整互動測試模式。

Restore dependencies with Node 26 and `npm ci`, then use `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build`. Verified V37 outputs become immutable; later behavior must use the next numbered version.
