# Main App V38 Source / 主應用程式 V38 原始碼

This is the React, TypeScript, and Vite source for Encounter Cards V38. It preserves the complete v37 desktop studio and adds one-viewport mobile fitting, bounded post-draw controls, and reliable grid-guided artwork adjustment with extended position and zoom ranges.

此處保存 Encounter Cards V38 source；完整保留 v37 桌面工作室，並新增手機單頁適配、抽卡後控制列安全邊界，以及可儲存的九宮格照片位置與縮放調整。

Restore dependencies with Node 26 and `npm ci`, then use `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build`. Verified V38 outputs become immutable; later behavior must use the next numbered version.
