# Main App V33 Source / 主應用程式 V33 原始碼

This is the React, TypeScript, and Vite source for Encounter Cards V33. It preserves the complete v32 experience, adds twelve Taiwan Astral Guardians, and provides a collapsed session-only control for independently choosing an exact artwork and/or exact eligible question while random remains the default.

此處保存 Encounter Cards V33 source；完整保留 v32 體驗，新增 12 張台灣星座守護者，並以折疊、僅限當次使用的控制，讓使用者可分開指定卡面與符合條件的問題；預設仍為隨機。

Restore dependencies with `npm ci`, then use `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build`. Verified V33 outputs become immutable; later behavior must use the next numbered version.
