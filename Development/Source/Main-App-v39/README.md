# Main App V39 Source / 主應用程式 V39 原始碼

This is the React, TypeScript, and Vite source for Encounter Cards V39. It preserves the complete v38 product and desktop studio while adding full-width mobile reflow, a three-mode home, an icon-only menu, and a direct downloadable keepsake maker.

此處保存 Encounter Cards V39 source；完整保留 v38 產品與桌面工作室，並新增全寬手機排版、三模式入口、純圖示選單，以及可直接下載的紀念卡製作器。

Restore dependencies with Node 26 and `npm ci`, then use `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build`. Verified V39 outputs become immutable; later behavior must use the next numbered version.
