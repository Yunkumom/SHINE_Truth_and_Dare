# Main App V32 Source / 主應用程式 V32 原始碼

This is the React, TypeScript, and Vite source for Encounter Cards V32. It preserves the complete v31 experience and all 18 portrait-safe artworks while adding separate desktop Settings/Test modes, a mobile play-only branch, stable opt-in layout manipulation, no-clipping text rules, and governed collection/artwork selection.

此處保存 Encounter Cards V32 source；完整保留 v31 體驗與 18 張人像安全圖，並加入桌面設定／測試模式、手機純遊玩分支、穩定的選用版面拖拉、不裁切文字規則，以及受治理的牌組／卡面選擇。

Restore dependencies with `npm ci`, then use `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build`. Verified V32 outputs become immutable; later behavior must use the next numbered version.
