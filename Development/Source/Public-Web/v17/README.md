# Public Web v17 Recipe / 公開版 v17 產製說明

Public Web v17 is the immutable Pages artifact generated from `Development/Source/Main-App-v34/dist/` by `Development/Automation/Scripts/finalize-public-v17.mjs` after the v34 tests, typecheck, lint, and PWA build pass.

Public Web v17 是由已驗證的 `Development/Source/Main-App-v34/dist/` 經 `finalize-public-v17.mjs` 複製產生的不可變 Pages 成品。成品位於 `Apps/Public-Web/v17/`；不得覆寫，後續變更需建立新版本。
