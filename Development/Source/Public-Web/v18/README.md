# Public Web v18 Recipe / 公開版 v18 產製說明

Public Web v18 is the immutable Pages artifact generated from `Development/Source/Main-App-v35/dist/` by `Development/Automation/Scripts/finalize-public-v18.mjs` after the v35 tests, typecheck, lint, PWA build, and card-library browser checks pass.

Public Web v18 是由已驗證的 `Development/Source/Main-App-v35/dist/` 經 `finalize-public-v18.mjs` 複製產生的不可變 Pages 成品。成品位於 `Apps/Public-Web/v18/`；不得覆寫，後續變更需建立新版本。
