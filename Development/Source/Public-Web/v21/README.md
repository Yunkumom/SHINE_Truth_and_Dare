# Public Web v21 Recipe / 公開版 v21 產製說明

Public Web v21 is the immutable Pages artifact generated from `Development/Source/Main-App-v38/dist/` by `Development/Automation/Scripts/finalize-public-v21.mjs` after the v38 tests, typecheck, lint, PWA build, and 1366 × 768 desktop-studio browser checks pass.

Public Web v21 是由已驗證的 `Development/Source/Main-App-v38/dist/` 經 `finalize-public-v21.mjs` 複製產生的不可變 Pages 成品。成品位於 `Apps/Public-Web/v21/`；不得覆寫，後續變更需建立新版本。
