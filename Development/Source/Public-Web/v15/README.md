# Public Web v15 recipe / 公開網站 v15 產製說明

Public Web v15 is generated from the verified `Development/Source/Main-App-v32/dist/` output by `Development/Automation/Scripts/finalize-public-v15.mjs`. It publishes separate desktop Settings and Test modes, a mobile play-only surface, safe typography, and advanced collection/artwork selection while preserving the 430 × 932 phone contract and local-only privacy boundary.

Public Web v15 由已驗證的 v32 `dist/` 透過 `finalize-public-v15.mjs` 產製，發布分離的桌面設定／測試模式、手機純遊玩介面、安全文字排版及進階牌組／卡面選擇，同時保留 430 × 932 手機規格與本機隱私邊界。
