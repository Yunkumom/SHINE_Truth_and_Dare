# Public Web v22 / 公開網頁 v22

Public Web v22 is the immutable GitHub Pages artifact built from verified Encounter Cards v39 source.

Build from `Development/Source/Main-App-v39/` with Node 26, run the complete tests, typecheck, lint, and production build, then run `Development/Automation/Scripts/finalize-public-v22.mjs` once. Later product changes require a new source and public version.
