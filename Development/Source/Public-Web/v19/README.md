Public Web v19 is the immutable Pages artifact generated from `Development/Source/Main-App-v36/dist/` by `Development/Automation/Scripts/finalize-public-v19.mjs` after the v36 tests, typecheck, lint, PWA build, and mobile-settings browser checks pass.

Public Web v19 是由已驗證的 `Development/Source/Main-App-v36/dist/` 經 `finalize-public-v19.mjs` 複製產生的不可變 Pages 成品。成品位於 `Apps/Public-Web/v19/`；不得覆寫，後續變更需建立新版本。
