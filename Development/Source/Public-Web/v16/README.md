# Public Web v16 recipe / 公開網站 v16 產製說明

Public Web v16 is generated from the verified `Development/Source/Main-App-v33/dist/` output by `Development/Automation/Scripts/finalize-public-v16.mjs`. It publishes twelve Taiwan Astral Guardians and independent exact artwork/question choices while preserving random defaults, desktop Settings/Test, mobile play-only, the 430 × 932 phone contract, and local-only privacy.
