Public Web v20 is the immutable Pages artifact generated from `Development/Source/Main-App-v37/dist/` by `Development/Automation/Scripts/finalize-public-v20.mjs` after the v37 tests, typecheck, lint, PWA build, and 1366 × 768 desktop-studio browser checks pass.
