# Main App V36 Source / 主應用程式 V36 原始碼

This is the React, TypeScript, and Vite source for Encounter Cards V36. It preserves the complete v35 experience and integrates the mobile ChatGPT Work settings, governed 42-artwork picker, session-only question management, and per-artwork adjustment controls.

此處保存 Encounter Cards V36 source；完整保留 v35 體驗，並整合手機 ChatGPT Work 的設定介面、42 張受治理卡面選擇、僅限當次 session 的問題管理，以及逐張卡面位置調整。

Restore dependencies with Node 26 and `npm ci`, then use `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build`. Verified V36 outputs become immutable; later behavior must use the next numbered version.
