# Main App V35 Source / 主應用程式 V35 原始碼

This is the React, TypeScript, and Vite source for Encounter Cards V35. It preserves the complete v34 experience and adds a virtualized, swipeable entrance card library for all 42 governed faces while random remains the default.

此處保存 Encounter Cards V35 source；完整保留 v34 體驗，並新增可自然左右滑動的入口卡庫，讓 42 張受治理卡面都能以完整卡片瀏覽；預設仍為隨機。

Restore dependencies with `npm ci`, then use `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build`. Verified V35 outputs become immutable; later behavior must use the next numbered version.
