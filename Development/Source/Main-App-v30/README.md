# Main App v30 Source / 主應用程式 v30 原始碼

This is the React, TypeScript, and Vite source for Encounter Cards v30. It preserves the complete v29 experience and replaces all 18 deity artworks with 2:3 portrait-safe masters that retain more surrounding scene, complete crowns, and centrally protected Taiwan motifs.

此處保存 Encounter Cards v30 source；完整保留 v29 體驗，並將 18 張神祇圖全部換成 2:3 人像安全 master，保留更多四周場景、完整頭冠與中央安全區內的台灣圖形。

Restore dependencies with `npm ci`, then use `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build`. Verified v30 outputs become immutable; later behavior must use the next numbered version.
