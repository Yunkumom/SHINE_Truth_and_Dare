# Main App v29 Source / 主應用程式 v29 原始碼

This is the React, TypeScript, and Vite source for Encounter Cards v29. It preserves the complete v28 experience and adds independently adjustable, larger question and blessing typography synchronized across the game card, phone preview, keepsake, and PNG export.

此處保存 Encounter Cards v29 source；完整保留 v28 體驗，並加入可獨立調整、預設更清楚的問題與祝福字級，同步套用於遊戲卡、手機預覽、紀念卡與 PNG。

Restore dependencies with `npm ci`, then use `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build`. Verified v29 outputs become immutable; later behavior must use the next numbered version.
