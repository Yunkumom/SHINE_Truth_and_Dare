# Taiwan Zodiac / 台灣星座

This folder contains original western-zodiac interpretations designed specifically for Taiwan. Every accepted image integrates a complete Taiwan main-island silhouette and recognisable Taiwanese scenery or craft detail without using protected Indigenous regalia or sacred patterns.

本資料夾保存以台灣為文化場景重新詮釋的十二星座原創圖。每張合格圖片都包含完整的台灣本島輪廓與可辨識的台灣景觀或工藝細節，且不挪用受保護的原住民族服飾或神聖紋樣。
