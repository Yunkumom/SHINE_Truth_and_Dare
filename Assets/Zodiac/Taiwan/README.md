# Taiwan Zodiac / 台灣星座

This folder contains original western-zodiac interpretations designed specifically for Taiwan. Every accepted image integrates a complete Taiwan main-island silhouette and recognisable Taiwanese scenery or craft detail without using protected Indigenous regalia or sacred patterns.

本資料夾保存以台灣為文化場景重新詮釋的十二星座原創圖。每張合格圖片都包含完整的台灣本島輪廓與可辨識的台灣景觀或工藝細節，且不挪用受保護的原住民族服飾或神聖紋樣。

- `v33-masters/` preserves the first classical, personified guardian interpretation as a reusable backup series.
- `v34-local-stories-masters/` contains twelve zodiac-led Local Stories images, bilingual feature notes, a manifest, and a contact sheet. The zodiac animal or symbol leads where appropriate; modern Taiwanese people appear only where the concept benefits from them.

- `v33-masters/` 保留第一套人物化古典守護者，作為可選與可重用的備用形象。
- `v34-local-stories-masters/` 保存十二張以星座原型與台灣地方故事為主的新圖、雙語特色註記、manifest 與 contact sheet；適合時由動物或星座符號擔任主體，人物則採現代台灣造型。
