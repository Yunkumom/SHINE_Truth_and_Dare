# v33 Taiwan Astral Guardian Masters

These twelve high-resolution vertical masters are the reusable source assets for Encounter Cards v33. They intentionally include extra scenery around the subject so the 430 × 932 card crop can preserve the face, head ornament, zodiac attributes, and complete Taiwan silhouette.

這十二張高解析直式 master 是相遇卡 v33 的可重用來源素材。構圖刻意保留較多周圍場景，使 430 × 932 卡面裁切後仍能保留臉部、頭飾、星座特徵與完整台灣輪廓。

`manifest.json` records identity, cultural cues, safe composition intent, generation provenance, and the corresponding runtime filename. Runtime-optimised WebP copies belong to the versioned v33 source and must not replace these masters.

`manifest.json` 記錄每張圖的識別、文化元素、安全構圖、生成來源與 runtime 檔名。最佳化 WebP 副本屬於 v33 版本 source，不得取代此處 master。
