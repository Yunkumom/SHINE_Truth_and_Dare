# Zodiac Assets / 星座素材

Reusable zodiac artwork is grouped first by country or cultural context, then by the release that established the masters. Each country folder must document its visual language, cultural limits, and runtime-copy location.

可重用星座圖依國家或文化脈絡分類，再依建立 master 的版本保存。每個國家資料夾都必須註明視覺語言、文化界線與 runtime 副本位置。
