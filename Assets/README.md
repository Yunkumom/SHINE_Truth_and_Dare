# Assets / 素材庫

This directory is the home for reusable source resources and their governance. `Catalog/` records licences, provenance, attribution, and cultural-safety limits. Version-bound runtime copies remain inside the relevant app or source tree for reproducibility.

本目錄是可重用原始素材與素材治理的集中位置。`Catalog/` 記錄授權、來源、標示與文化安全限制。為確保可重建性，版本綁定的 runtime 副本仍保留於對應 App 或 source 內。

`Deities/` contains the original deity portraits, later variants, and `baosheng-dadi-apothecary-wide-taiwan-safe-v28.png`, the current wider source with complete crown clearance and a central Taiwan enamel. `Deities/v20-variants/` contains nine additional poses/actions; `Deities/v23-taiwan-safe/` preserves the prior 18 high-resolution Taiwan-safe edits. Version-bound runtime copies live in the immutable release sources and current `Development/Source/Main-App-v28/src/assets/deities/`.

`Deities/` 保存原始神祇圖、後續變體，以及目前構圖更寬、頭冠完整、台灣琺瑯位於中央安全區的 `baosheng-dadi-apothecary-wide-taiwan-safe-v28.png`。`Deities/v20-variants/` 保存另外九張姿勢／動作變體；`Deities/v23-taiwan-safe/` 保留先前 18 張台灣安全圖。版本綁定副本保留於不可變 release 與目前 v28 source。
