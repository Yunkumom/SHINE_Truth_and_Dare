# Assets / 素材庫

This directory is the home for reusable source resources and their governance. `Catalog/` records licences, provenance, attribution, and cultural-safety limits. Version-bound runtime copies remain inside the relevant app or source tree for reproducibility.

本目錄是可重用原始素材與素材治理的集中位置。`Catalog/` 記錄授權、來源、標示與文化安全限制。為確保可重建性，版本綁定的 runtime 副本仍保留於對應 App 或 source 內。

`Deities/` contains the original deity portraits and later variants. `Deities/v30-safe-masters/` is the current reusable collection of 18 high-resolution 2:3 masters with expanded scenery, complete crown clearance, and centrally protected Taiwan motifs. Version-bound WebP copies live in `Development/Source/Main-App-v30/src/assets/deities/`.

`Deities/` 保存原始神祇圖與後續變體；`Deities/v30-safe-masters/` 是目前可重用的 18 張高解析 2:3 master，具有擴充場景、完整頭冠留白與中央安全區台灣圖形。版本綁定 WebP 副本位於 v30 source。
