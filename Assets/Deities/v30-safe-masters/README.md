# v30 portrait-safe deity masters / v30 人像安全神祇原圖

This folder contains 18 project-owned 1024 × 1536 PNG masters generated with OpenAI built-in image generation on 2026-07-27. Baosheng Dadi's successful rainy-apothecary composition was used only as the project-owned style and safe-framing reference.

本資料夾保存 18 張專案自有的 1024 × 1536 PNG master，於 2026-07-27 使用 OpenAI 內建圖片生成建立；成功的保生大帝雨夜藥房構圖僅作為專案自有畫風及安全構圖參考。

Shared production contract:

- Vertical 2:3 master with substantially more surrounding scene than the near-square card crop.
- Full face, hair, crown, and every ornament point remain inside the central safe area with generous sky/interior clearance.
- One complete, contrasting, geographically recognizable Taiwan main-island silhouette is embedded in a central garment or prop, never at an image edge.
- No text, card frame, logo, watermark, modern object, or copied third-party artwork.
- Runtime WebP derivatives live in `Development/Source/Main-App-v30/src/assets/deities/`; these PNG files remain the reusable masters.

共同製作合約：原圖保留比卡片更多的四周場景；臉、頭髮、完整頭冠與所有垂飾均在中央安全區；一個完整、對比清楚且可辨識的台灣本島輪廓藏於中央服飾或器物；不得加入文字、卡框、標誌、浮水印、現代物件或第三方作品。程式使用的 WebP 衍生檔位於 v30 source，本目錄保留可重用 PNG 原圖。
